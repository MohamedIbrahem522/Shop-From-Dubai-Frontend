# Shop From Dubai - Frontend

Storefront for **Shop From Dubai**, an Arabic (RTL) online store I built as a freelance project for a client who sells products from Dubai.

**Live site:** https://shop-from-dubai-frontend.pages.dev/
**Backend repo:** https://github.com/MohamedIbrahem522/Shop-From-Dubai-Backend

## Features

- Arabic right-to-left layout, mobile friendly
- Product and category browsing
- Customer reviews section
- Content managed by the admin through the backend API
- Data cached in LocalStorage and images compressed to WebP for faster loading

## Tech

HTML, CSS and vanilla JavaScript, with Google Fonts (Tajawal), AOS animations and Font Awesome. Hosted on Cloudflare Pages.

## Run locally

No build step. Clone the repo and serve the folder:

```bash
git clone https://github.com/MohamedIbrahem522/Shop-From-Dubai-Frontend.git
cd Shop-From-Dubai-Frontend
npx serve .
```
